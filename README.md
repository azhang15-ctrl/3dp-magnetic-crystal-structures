# 3dp-magnetic-crystal-structures
3D-printed crystal structure models with embedded magnets for easy assembly/disassembly.

Interactive 3D crystal models can be a powerful tool for understanding the physical spatial arrangement of atoms in crystals.
Magnetic connections between atoms allows for easy assembly, as well as some physical flexibility in the structure.

Each magnet is embedded in the ball in a built-in press-fit socket. The mechanism is similar to that in an annular snap-fit, consisting of a ring with one slot and outer groove to allow the ring to slightly expand. If needed, the magnet can be removed from a press-fit socket using a sharp tool and re-inserted. All of the sockets on each ball are identical and their rotational position does not matter, hence they are known as two-way connectors. A pair of two-way connectors on two balls will stick together if the two embedded magnets are of opposite polarity, creating a secure connection (although it is able to freely rotate).
